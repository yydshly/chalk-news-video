# MVP Demo Script（3–5 分钟）

## 开场话术（30 秒）

> "这个工作台解决的是：从可信来源获取新闻信息，快速变成可预览、可导出、可发布准备的新闻短视频。
>
> 它的核心链路是：来源输入 → 草稿篮 → 栏目合同 → 预览 → MP4 导出 → 发布素材包。"

---

## Demo 1：来源收集（1 分钟）

### 步骤 1：展示可靠来源 Registry

- 打开 `/api/reliable-sources` 或在 UI 中展示内置来源列表
- 展示域名识别能力

> "第一步，我们有一个可信来源列表。"

### 步骤 2：URL 草稿篮（Draft Basket）

- 添加 2–3 个 URL（如 OpenAI News、arXiv）
- 展示草稿卡片出现

> "把 URL 加到草稿篮（Draft Basket）里。"

### 步骤 3：URL 抽取或手动编辑

- 点击抽取，观察 title/description 自动填充
- 或直接在标题/摘要框里手动输入

> "可以从网页抽取标题和摘要，也可以手动填。"

### 步骤 4：保存来源集合

- 输入集合名称，点击保存
- 刷新页面后展示恢复功能

> "还可以把当前这组来源保存成一个集合，方便下次恢复。"

---

## Demo 2：生成栏目（1 分钟）

### 步骤 5：从草稿篮生成 Contract

- 点击"生成栏目"
- 观察 API 调用和 contract 生成

> "填好草稿之后，一键生成栏目合同（Source Contract）。"

### 步骤 6：Inspector 检查

- 展示生成的合同内容（JSON 或 UI）
- 确认标题、来源、时间线标记

> "生成之后可以检查合同内容是否正确。"

### 步骤 7：Apply to Planner

- 点击"应用到 Planner"
- 观察 planner 状态更新

> "确认无误后，应用到 Planner，准备生成预览。"

---

## Demo 3：视频生产（1.5 分钟）

### 步骤 8：查看 Workflow Checklist

- 展示 Production Workflow Panel
- 展示哪些步骤已完成、哪些待处理

> "生产检查清单会实时告诉我们进行到哪一步了。"

### 步骤 9：选择样式并 Preview

- 选择一个 9:16 样式
- 展示 HTML 预览

> "选择一个竖屏样式，立刻看到视频画面预览。"

### 步骤 10：导出 MP4

- 点击"导出 MP4"
- 观察异步任务状态轮询
- 等待导出完成（约 10–20 秒）

> "确认画面满意之后，提交 MP4 导出。后台异步处理，等待完成。"

### 步骤 11：验证导出历史

- 打开导出历史
- 确认新导出任务存在

> "导出完成后可以在历史里找到它。"

---

## Demo 4：发布准备（1 分钟）

### 步骤 12：生成 Publish Package

- 点击"生成发布素材包"
- 观察标题/简介/平台文案/标签/封面提示词自动填充

> "MP4 导出完成后，我们可以一键生成发布素材包。"

### 步骤 13：复制字段

- 点击某个字段的"复制"按钮

> "每个字段都可以一键复制，直接粘贴到目标平台。"

### 步骤 14：导出 JSON/Markdown

- 点击"导出 JSON"
- 点击"导出 Markdown"
- 展示浏览器下载

> "也可以把完整的发布包导出为 JSON 或 Markdown，留作归档或交给别人发布。"

---

## 结束话术（15 秒）

> "到这里，整个链路就跑通了：来源 → 草稿 → 合同 → 预览 → MP4 → 发布素材包。
>
> 当然，它现在还不是一个全自动新闻生产系统——没有真实新闻 API、没有 AI 改写、没有平台自动发布。
>
> 但已经有了可跑通的 MVP 闭环。下一阶段可以选择接入真实 LLM/TTS、Remotion、或平台发布 API。"

---

## 演示注意事项

| 场景 | 建议 |
|------|------|
| 网络不稳定 | 提前准备好本地 sample 新闻演示 |
| URL 抽取失败 | 切换到手动编辑演示 |
| MP4 导出慢 | 可跳过等待，提前准备已导出的 MP4 |
| 时间不够 | 跳过 Demo 1，只演示 Demo 2–4 |
| 观众技术背景强 | 可深入讲 contract schema 和 API 设计 |
| 观众非技术背景 | 重点演示 UI 操作和最终产物 |
