# CP52 Route Comparison Matrix

## 四条路线综合对比

| Route | 核心价值 | 实现成本 | 外部依赖 | 技术风险 | 商业价值 | 推荐优先级 | 结论 |
|-------|----------|----------|----------|----------|----------|-----------|------|
| **A 真实新闻采集** | 解决信息源自动化 | 中 | RSS/HTML 来源 | 中（反爬/JS渲染） | 高（信息聚合壁垒） | **第一优先** | 基础能力，必做 |
| **B Real LLM/TTS** | 解决内容质量 | 高 | LLM API + TTS API | 中（成本/幻觉） | 高（内容差异化） | **第二优先** | 核心体验提升 |
| **C Remotion 视觉** | 解决视觉效果 | 极高 | Remotion + React/TS | 高（工程复杂） | 中（锦上添花） | 暂缓 | 后置，内容>视觉 |
| **D 多用户产品化** | 解决商业化 | 极高 | 数据库/云存储/OAuth | 高（运维/安全） | 潜在 | 暂缓 | 过早，单用户价值未验证 |

## 能力问题 →最适合路线

| 能力问题 | 当前状态 | 最适合路线 | 说明 |
|----------|----------|------------|------|
| 每天信息从哪里来 | 未解决（手动填 URL） | **Route A** | 真实来源采集最小闭环 |
| 视频内容是否足够好 | 部分解决（规则生成） | **Route B** | LLM 摘要/改写/脚本 |
| 视频是否足够好看 | 初步解决（Python renderer） | **Route C**（后置） | Remotion 高版本视觉 |
| 是否可商业化交付 | 未解决 | **Route D**（后置） | 多用户 SaaS |
| 是否可稳定端到端演示 | **已解决** | 当前 MVP | CP51 v0.1 已验证 |
| 脚本是否足够自然 | 未解决 | **Route B** | LLM 生成旁白 |
| 是否有配音/口播 | 未解决 | **Route B** | TTS 接入 |
| 是否有字幕轨 | 未解决 | **Route B** | TTS + script 对齐 |

## 路线依赖关系

```
Route A（来源采集） ──────┐
                         ├──► Route B（内容质量）──► Route C（视觉）──► Route D（产品化）
Route A（候选审查 UI）───┘
```

说明：
- Route A 最基础，不依赖其他路线
- Route B 依赖 Route A 的候选内容
- Route C 依赖 Route B 的内容质量（内容稳定后再做视觉）
- Route D 依赖 Route A+B 的核心价值验证

## 成本估算（相对）

| Route | 研发时间 | API 成本 | 工程复杂度 | 运维复杂度 |
|-------|----------|----------|------------|------------|
| A 真实采集 | 中（2–3 CP） | 低 | 中 | 低 |
| B LLM/TTS | 高（3–4 CP） | 高（按 token） | 中 | 低 |
| C Remotion | 极高（4–5 CP） | 中 | 极高 | 高 |
| D 多用户产品化 | 极高（5–6 CP） | 高 | 极高 | 极高 |

## 风险矩阵

| 路线 | 主要风险 | 概率 | 影响 | 缓解措施 |
|------|----------|------|------|----------|
| A | 反爬/403/JS渲染 | 中 | 高 | 优先选 RSS + 静态 HTML，允许手动兜底 |
| B | LLM 幻觉/成本失控 | 中 | 中 | 加 facts guard，设置 token 预算 |
| B | TTS 音色质量 | 低 | 中 | 选成熟 TTS 服务，多音色对比 |
| C | 工程复杂度失控 | 高 | 高 | 只做 1 个模板 spike，不全量替换 |
| D | 过早产品化 | 高 | 中 | 先验证单用户核心价值再扩张 |

## 各路线"不做"边界

| 路线 | 明确不做 |
|------|----------|
| A | 不做 JS 动态渲染爬虫、不做全自动无审查采集 |
| B | 不做全自动事实补全、不做无 guard 的 LLM 生成 |
| C | 不全量替换 Python renderer、不做复杂 3D 动画 |
| D | 不做无价值验证的 SaaS、不做复杂权限计费系统 |
